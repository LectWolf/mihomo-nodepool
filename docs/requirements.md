## 产品与部署

- 项目名 Mihomo NodePool；仓库 LectWolf/mihomo-nodepool，初始为私有仓库。
- 中文 Vue 3＋TypeScript＋Vite 网页、Go 后端、内嵌 Mihomo；Docker 单应用容器连接已有外部 MySQL。
- 参考 LinkSyncX/linksyncx 的检测、排除规则、更新／回退机制，已核对参考提交 e7f208eae7125e02ba3ccde882fd7ce99aa51f79。参考源码仅存临时目录。
- 数据库升级仅补充所需表、列及索引，保留既有节点身份、来源归属、关系、缓存和检测历史。来源 URL 唯一性由全局迁移为用户＋URL 哈希。
- 当前单应用实例部署；不附带新业务数据库，不连接业务库做测试，不发布版本或部署，除非用户另行授权。

## 节点与来源

- 导入订阅 URL、本地文件、节点分享链接；支持批量导入。面向数百来源、数千节点，受控容量目标为 500 来源／10,000 唯一节点。
- 唯一节点按规范化完整有效配置全局去重；显示名称不参与，密码、UUID、TLS、SNI、传输等参数参与。同名、地址或出口相同本身不构成去重依据。
- 来源与唯一节点分别存储，关系保留原始名称和用户归属。删除来源保留其他来源仍引用的节点；刷新失败保留上次成功内容。
- 全局和来源名称排除正则共同生效；被排除节点不进入正常列表、可选范围或订阅输出。修改规则按保存快照重算，不刷新全部上游。
- 默认节点卡片，卡片／列表使用图标切换且卡片在前；刷新仅图标。卡片不显示最近／下次检测与固定周期文案。
- 卡片布局紧凑扁平，标题最多一行，省略内容悬浮展示全文。平时整卡查看详情，显式进入选择模式后整卡选择；检测只在管理员详情中可见。
- 支持搜索、协议、来源、国家／地区多选、健康状态、排序及分页。移除最大延迟网页筛选及 URL 状态，API 兼容旧参数。
- 来源筛选使用可搜索分页面板，地区使用国旗网格多选，具备“全部”、清空和多选摘要；桌面每行 5 项，名称保持单行，超出在内部滚动。地区网格参考本机订阅共享 CatalogView／RegionCell。
- 桌面搜索和筛选同一行，窄屏合理换行；所有浮层自绘，支持键盘、触屏、Escape、焦点恢复和弹窗内使用。
- 所有表单统一为标签一行、输入一行、说明一行（可选），可选标记与标签同行，并排输入框对齐。
- 亮暗首次跟系统，太阳／月亮图标切换后持久化偏好。版本入口为真实版本纯文字；顶栏移除正常数据库状态，侧栏移除自动维护说明，异常仍需可见。
- 节点、来源、提供方、订阅、账号、用户管理和设置使用独立页面 URL。分页、筛选和视图支持刷新及浏览器前进后退。

## 账号、提供方与领取

- 保留管理员 ID=1、初始密码和既有来源；旧登录省略用户名时兼容 admin。管理员创建普通账号，不开放自助注册。
- 管理员创建／停用用户、重置密码、逐用户调整额度。普通用户无需审核即可上传、启停、刷新、修改和删除本人来源。
- 全局设置、更新／回退／重启、Release 查询、所有手动探测仅管理员；包括普通用户本人来源节点也不能手动检测。权限由后端强制。
- 每次业务请求校验账号有效性；停用立即撤销会话和原订阅令牌，恢复启用不会使旧令牌复活。修改密码撤销其他会话。
- 提供方入口为 `/nodes?provider_id={id}`。支持发现、搜索、关注、取消关注，以及按已关注或指定提供方浏览节点。关注独立于领取。
- 来源可设最大领取人数，0 不限。按登录账号历史唯一计数：同账号领取同来源多个节点、多个组合、客户端重复刷新只计一人。
- 仅保存事务成功才占名额；并发最后一个名额不能超领，失败不占。删除组合／取消关注不回收历史领取，降低人数上限不影响已有领取人。
- 来源显示当前使用人数与历史领取人数。当前按仍有组合引用来源的启用账号去重，删掉最后引用或覆盖为其他来源后减少，历史上限语义不变。

## 额度与组合订阅

- 默认账号总额度：200 个唯一节点、3 个不同来源、1 条组合订阅；管理员可逐用户调整正整数额度。
- 额度按账号全部组合订阅合计，保存与输出均检查最新值；降低额度会影响后续输出。
- 节点支持跨页多选；同一节点有多个来源时明确领取归属。重复节点只计一次，来源归属由后端核验。
- 可选择整个来源，按来源／节点 ID 升序、去重后填入剩余额度；超出部分截断并提示，默认最多 200 个。未选中节点的来源不占领取名额。
- 整来源选择弹窗同时展示当前单选节点、整来源清单与每个来源的选中状态，可直接移除已有选择。
- 保存节点快照；来源后续刷新不会替换成用户未选择的节点。删除关系、停用来源／提供方、排除和屏蔽均会过滤输出。
- 组合页面支持查看、编辑、删除、复制自动／Clash／v2ray 地址和轮换令牌。编辑原样保留节点快照，整来源扩选必须由用户主动选择。
- 满额时仍可选择节点，保存时可覆盖已有组合并保留原令牌；校验用量时排除被覆盖组合。组合详情可查看快照清单。
- 客户端 `/sub/{token}` 不依赖登录 Cookie；删除或轮换令牌后旧地址立即失效。提供方入口与个人客户端下载地址分开。
- Clash 返回保留完整配置的 YAML；v2ray 返回可保真分享 URI 按行组合后的 Base64。显式格式优先，其余按 UA 选择，未知 UA 默认 Clash。
- 无法完整表达的协议参数应跳过并报告数量，全部不可转换返回 422。不能丢参数生成假节点，不能把 URI 集合冒充 sing-box JSON。

## 规则组合

- 每个账号可创建多个私人规则组合，支持编辑、复制和删除；在保存组合订阅或我的订阅中选择绑定。
- 默认分流沿用本机“订阅共享”完整规则表，包含自动选择、故障转移、Cloudflare、国内直连、广告拦截和兜底，可自行编辑规则。
- 分流开启时覆盖来源规则，关闭时保留缓存来源中可安全合并的本地规则与策略组；同名组按来源区分，只含已选节点，无来源规则则 NodePool 兜底。
- DNS 独立开关；启用且留空默认 223.5.5.5、119.29.29.29、8.8.8.8，关闭不写入 DNS。
- 仅影响 Clash；v2ray 不受影响，旧订阅不强制自动绑定。已绑定规则不可直接删除，先解绑以防静默改变输出。

## 调度与检测

- 来源刷新和节点成功后的检测采用 6 小时正常周期，按各自加入时间稳定错峰。失败检测按 1、2、4、8、16 小时递增，之后上限 24 小时。
- 首次检测排队执行，同批节点在 30 秒内错峰；重复配置只检测一次。队列、下次执行时间和租约持久化，重启恢复，错过周期合并补跑。
- Mihomo URLTest 默认 generate_204、5 秒超时、16 并发；单次探测内失败重试一次。连续 3 次任务失败标不可用，一次成功清零并恢复健康。
- 连续 7 天未成功则持久化屏蔽；从未成功以创建时间为准，来源刷新不重置历史。普通读取、统计和调度排除，明确 ID 手动复测成功可恢复。
- 出口 IP、国家、省／州和城市经对应节点获取，正常缓存 24 小时；第三方位置服务失效不会将可用节点判为不可用。不做 AI 平台解锁检测。

## 版本与发布

- 点击版本文字查看发布信息。管理员可从 GitHub Release 下载安装对应架构程序，校验后保留本地 backup 并替换。
- Linux 重启通过退出进程，由 Docker restart 策略拉起。Windows 本地可查看版本，不执行在线替换或立即重启。
- 支持本地程序备份回退及安装允许的历史 Release。回退只切换程序文件，不备份、回滚或校验数据库版本。
- 稳定标签工作流生成 Linux AMD64／ARM64 发行包、校验文件、GHCR 多架构镜像和 Release。普通 PR 仅运行 CI。
- 容器内更新与镜像版本分开，重建使用所选镜像版本。首次正式发布及真实私有资产升级需发版后验证。
