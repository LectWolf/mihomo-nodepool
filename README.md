# Mihomo NodePool

中文节点管理网页，使用 Vue 3、TypeScript、Go、内嵌 Mihomo 和外部 MySQL。通过 Docker 单容器部署。

## 功能

- 导入订阅 URL、本地 Clash YAML/JSON 文件、Base64 订阅和 Mihomo 支持的节点分享链接；支持批量来源。
- 按完整连接配置生成指纹，跨来源去重。节点名称不参与指纹，密码、UUID 和传输参数参与；来源与原始名称保留。
- 节点默认卡片展示，可用图标切换到列表；支持分页、名称、地址、协议、地区网格多选、可搜索分页来源和健康状态筛选。国旗 SVG 随应用打包，出口显示 IP 及“国家 · 省／州 · 城市”。
- 全局与单来源名称排除正则；默认排除剩余流量、到期说明等信息节点。被排除节点不进入有效列表。
- 订阅来源每 8 小时按加入时间稳定错峰刷新；刷新成功后接着检测该来源的节点（新节点优先，同一来源每 3 秒排一个，多个来源并行），6 小时内测过的共有节点不重复检测。限并发、持久化队列与任务租约，重启后恢复。
- 来源刷新后，订阅里已消失的节点自动换成该来源中同名的新节点。
- 检测频率按使用情况分级（在用 8 小时、来源有人占席位 16 小时、无人使用默认 3 天，可设为不定期检测）；最近一次国内回报能连的健康节点暂停本机检测最长 24 小时。
- 国内用户实测结果优先于本机延迟参与排序，统计窗口可设 1–7 天。
- 节点列表使用内存索引，不再每次请求都对全部节点做子查询；后台标签页暂停自动刷新。每日清理过期数据。
- 使用内嵌 Mihomo URLTest；失败检测按 1、2、4、8、16 小时退避，之后最多 24 小时。连续 7 天未成功则屏蔽，成功后解除屏蔽并恢复正常排期。通过节点查询出口信息，不包含 AI 平台解锁检测。
- 客户端实测回报（默认开启，可在账号里关闭）：Clash 订阅附最多 15 个隐藏检测组，客户端每小时经节点访问本站 `http://<主机>/b/<令牌>`，每次更新订阅（间隔超过 1 小时）换一批该用户没测过的节点，统计国内用户能否连通并显示在节点卡片上；用户自己连不上的节点排到其订阅末尾。
- 用户名登录、管理员创建账号及调整额度；普通用户管理自己的上传来源，支持提供方入口和关注。
- 节点跨页多选、整来源按剩余额度截取并保存组合订阅；默认账号合计200个唯一节点、3个来源、1条组合。来源支持有效席位上限与最低账号等级。
- 个人 `/sub/{token}` 支持 Clash／Mihomo YAML 和 v2ray 兼容 URI Base64；可删除或重置令牌，客户端刷新无需 Cookie。
- 版本文字读取真实版本，管理员可查看 GitHub Release、更新、回退和立即重启；**回退只切换程序，不处理数据库**。
- 下拉和筛选浮层自绘，支持键盘和触屏；亮暗首次跟系统，太阳／月亮图标切换后保存在浏览器中。所有表单统一标签、输入、说明的行布局。
- 节点、来源、提供方、订阅、账号及管理员页面使用独立路由；分页、筛选及视图保存在 URL，支持直接访问、刷新和浏览器前进后退。
- 可编辑Cloudflare、自动选择、故障转移等策略组成员，支持国家组、指定节点及组间引用，拒绝循环引用。
- 14天个人租期、真实Mihomo保活探测、网页签到；等级经验与积分分开，当前／历史订阅用户管理、踢出禁领及解除。
- 来源整源专属直链、本地订阅二维码与六平台客户端入口；套餐状态、安全配置提示、v2ray URI兼容性紧凑披露。
- 管理员“运行统计”页（`/statistics`）展示来源、节点、账号和席位规模，执行中／排队的后台任务，来源套餐用量小计，以及本次启动以来的订阅正文下载量、来源处理与节点检测次数；空闲时每 15 秒刷新、有排队任务时每 3 秒刷新。
- 节点卡片中的 URI 不可导、TLS 证书验证关闭等配置提示以图标显示，悬停或详情查看完整说明；所有分页显示首页、尾页和当前页前后 2 页，其余以省略号表示。

节点请求、国家查询的结果受部署机器的网络、节点可达性及第三方查询服务影响。列表中的延迟是代理 HTTP 测试延迟，不是 ICMP ping。

完整需求和接口见 [requirements](docs/requirements.md) 与 [API](docs/api.md)。从旧版单点登录与订阅共享站迁移见 [旧站数据迁移](docs/legacy-migration.md)。

## Windows 本地运行

要求 Go 1.26+、Node.js 24 和 npm；数据库使用现有 MySQL 8.0+（CI 使用 MySQL 8.4）。

先准备配置：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`，填写 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`、`MYSQL_DATABASE`。建议设置至少 8 字节的 `ADMIN_PASSWORD`。然后执行：

```powershell
.\scripts\start.ps1 -Build
```

打开 `http://127.0.0.1:8080`。按 Ctrl+C 停止。后续不修改代码时可运行 `.\scripts\start.ps1`（去掉 `-Build`）。

管理员用户名为 `admin`。未设置初始密码时，首次启动会生成 `data/admin-password`，日志只显示路径；可在本机读取后登录。连接数据库后管理员账号和密码持久化，随后更改环境变量不会覆盖数据库中的密码，可在账号设置修改。没有 MySQL 时仅能使用原管理员连接提示，不能保存业务数据。

程序读取当前工作目录 `.env`，已有进程环境变量优先；可用 `NODEPOOL_ENV_FILE` 指定文件。Windows 启动脚本自动使用项目根目录配置。

启动脚本保存为带 BOM 的 UTF-8，同时兼容 Windows PowerShell 5.1 和 PowerShell 7 的中文解析。

## 开发与构建

```bash
npm ci --prefix frontend
node scripts/build.mjs
```

产物为 `build/nodepool`，Windows 为 `build/nodepool.exe`，已包含前端和 Mihomo。运行产物即可访问网页。

构建时默认写入 `git rev-parse HEAD`，工作区有未提交修改时追加 `-dirty`，无 Git 时为 `unknown`；`NODEPOOL_COMMIT`、`NODEPOOL_VERSION`（默认 `dev`）、`NODEPOOL_BUILD_TIME` 可覆盖。版本、内核版本、构建时间和提交属于运行中程序的静态信息，只有重新构建并启动或升级后才会变化；使用新版本前先停止旧程序，再运行 `.\scripts\start.ps1 -Build`。

开发时另开终端运行：

```bash
npm run dev --prefix frontend
```

前端地址 `http://127.0.0.1:5173`，代理 API 到 `127.0.0.1:8080`。后端仍运行上述构建产物；修改 Go 代码后重新构建并启动。

## Docker

`.env` 连接现有 MySQL；应用会在指定库中创建 `np_` 前缀表，需要建表和读写权限。旧版本升级需要 `ALTER` 权限：补充地区／屏蔽字段、来源人数上限、用户／关注／领取／订阅表，并把 URL 唯一索引迁移为用户＋URL 哈希；管理员 ID=1、既有来源／缓存／节点身份和检测历史保留。历史健康节点以最近检测时间初始化成功时间，其余以入库时间初始化失效基准。请使用独立数据库，并确保容器可访问实例。

从源码构建：

```bash
docker compose up -d --build
```

有正式版本后，使用 GHCR 镜像：

```bash
docker compose pull
docker compose up -d --no-build
```

默认网页端口 8080，可用 `HTTP_PORT` 更改。持久化目录 `/app/data` 保存自动生成的管理员密码等运行文件；业务数据在 MySQL 中。容器以 UID 1000 运行应用，启动脚本只在准备目录时使用 root。

当前按单应用实例部署。不要同时启动多个实例来扩容；全局并发上限及更新操作按单实例管理。

## 设置与数据行为

- 全局排除正则在运行设置中编辑，来源可单独追加规则。正则变化使用已保存内容重算，不刷新全部订阅链接。
- 相同配置在不同来源中只显示一行，展开节点详情可以查看来源和原始名称。同地址不同凭据不会合并。
- 删除来源只移除该来源关系；其他来源引用的节点继续保留。停用来源后它独有的节点不进入有效列表和检测。
- 订阅抓取或解析失败保留上次节点，来源卡片显示错误；自动刷新失败 15 分钟后重试。
- 节点成功后的兜底检测间隔为 9 小时（订阅来源刷新后会更早重排；文本和文件来源只靠兜底），失败进入指数退避。错过周期只补一次。
- 国家、省／州和城市通过对应节点获取，正常缓存 24 小时；旧记录缺少地区时会在下一次检测补查。第三方查询服务失效不会将可用节点判为不可用。
- 连续 3 次失败标为不可用，每次失败都会推进退避；一次成功即可恢复健康并清零失败次数。连续 7 天未成功的节点不进入有效列表、筛选选项和普通检测队列；仍可通过明确节点 ID 的检测 API 手动复测，成功后重新显示。

## 用户与订阅

管理员在“用户管理”创建账号，可按角色、状态、风控和额度筛选，调整节点／来源／订阅额度。默认开放自助注册（每 IP 每小时 5 次），也允许未登录访客浏览节点与提供方（不显示服务器地址）；两项都可在运行设置“访问与注册”关闭。在运行设置“登录与邮件”配置 SMTP 后，注册需验证邮箱，并支持邮箱登录、验证码登录与找回密码；配置 GitHub／LINUX DO OAuth 应用（回调 `{公开地址}/api/v1/auth/oauth/{github|linuxdo}/callback`）后可第三方登录，首次登录自动建号，之后需补齐邮箱。首次登录有分步新手引导，可在账号菜单重新查看。普通用户无需审核即可上传来源；全局设置、更新和手动检测仅管理员可操作，检测入口位于节点详情。

节点卡片默认点击查看详情；点击“选择节点”进入整卡选择模式，选区跨页保留，也可选择整个来源。整来源弹窗同时展示已有单选节点和来源选择状态。默认额度按账号全部组合合计，重复节点只计一次；整来源按节点顺序填剩余额度，超过时提示截断。保存的是固定节点快照，后续来源刷新不会自动替换为未选择的新节点。

来源按有效席位限制人数：同一启用账号引用同一来源多个节点／组合只占一个席位，保存失败不占。默认14天租期，过期、踢出、删除最后引用或覆盖为其他来源会释放容量；历史人数不再占用上限。降低上限保留未过期已有席位，过期回来须重新校验容量。提供方可查看当前／历史用户及相关时间和引用数量，踢出会移除该用户全部组合中的来源并禁止再次领取，直到明确解除。

“我的订阅”可查看组合、编辑节点、切换规则，选择 Clash／自动识别／v2ray 格式后复制链接、一键导入或扫码，也可删除或重置链接。修改或删除前的组合存入“历史组合”（每人保留最近 10 份），可恢复为新订阅或覆盖已有订阅；“席位记录”显示各来源席位的占用、续期与释放。数量或节点满额时，仍可选好节点，在保存弹窗选择覆盖已有组合；覆盖保留原订阅链接。令牌地址允许客户端下载节点凭据，应只交给自己的客户端；重置／删除后旧链接立即失效，停用账号会永久撤销当时的旧令牌。

网页签到或有效保活节点探测续租，登录、浏览和普通拉取不续租。过期拉取只返回签到激活提示节点；回网页激活遇到满额、停用或等级不足来源，会先列明并等待确认，确认后排除这些来源并激活其余。北京时间每日签到+5经验／+2积分，每连续7天额外+20经验／+8积分，同日不重复奖励。等级门槛0／50／200／1000／3500／10000／30000经验，对应初至／识途／通行／常客／熟路／向导／彼岸；来源默认Lv0不限。

每个来源均有 `/link/{token}` 整源专属订阅直链，仅所有者／管理员可获取和轮换，持有链接即可下载，绕过个人等级与席位；勿与个人 `/sub/` 混用。个人订阅提供浏览器本地二维码，不向第三方发送令牌，并列出iOS、安卓、macOS、Windows、Linux、OpenWrt客户端官方入口。组合查看与保存预览默认卡片。

运行设置可调整租期1–365天、历史保留1–3650天（默认30天），并设置反向代理后的公网HTTPS源地址；保活需要转发 `/ws/lease/` WebSocket Upgrade。来源事件、已结束席位、删除／覆盖前组合显示快照按保留期清理，禁领状态不随清理解除。详见[席位租期与历史](docs/inactive-source-seats-proposal.md)。

节点紧凑显示来源套餐余量／到期状态、配置风险及URI导出情况；详情解释原因。套餐元数据属于整个来源，不代表个人剩余流量；缺失表示未知。旧式SS流加密、明文协议配置、关闭证书验证、旧VMess alterId会提示；静态提示不等于已证实节点被攻击，SS AEAD／SS2022／WireGuard不因无TLS被判明文。

Clash 导出保留完整代理配置。v2ray 输出 v2rayN 等客户端通用的分享 URI：只要求连接必需的信息能完整表示，TFO、多路复用、UDP 开关、early data、除 Host 外的伪装请求头等客户端调优参数不保留；链式代理、未知协议、未知传输方式和插件（如 shadow-tls）无法连接，跳过并通过 `X-Subscription-Skipped` 报告数量。全部无法输出时返回只含一条提示节点的订阅（HTTP 200），避免客户端只报“无效的订阅内容”。需要完整配置时请使用 Clash 格式。此项目不提供 sing-box JSON。

所有账号直接拥有只读的“官方默认规则”，新建组合订阅默认选中，无需先复制。官方规则沿用本机“订阅共享”的完整分流规则，包含国内直连、广告拦截、自动选择和故障转移；可查看或复制成私人组合。私人规则工作台支持搜索、分页、逐条增改、顺序调整、文本编辑和撤销本次修改，DNS 独立设置。DNS 启用但留空时使用 `223.5.5.5`、`119.29.29.29`、`8.8.8.8`，关闭则不写入 DNS；分流关闭时合并缓存来源的本地规则与策略组。只影响 Clash，v2ray 保持原样。可显式选择不绑定；旧订阅不强制迁移。仍被订阅使用的私人规则须先解绑再删除。

每人最多 10 份私人规则。策略组支持手动选择、自动选择、故障转移、负载均衡；成员按“全部节点／国家／地区／其他组引用”组合，不再支持指定单个节点。包含全部节点的手动选择组会按订阅里出现的国家自动追加“🇭🇰 香港”这类自动选择分组；成员顺序为引用组、国家分组、节点。组不会额外领取节点，空匹配回退DIRECT。拦截广告组默认 REJECT，可在客户端切到 DIRECT。官方规则只读，可复制后修改Cloudflare等组。

地区筛选以勾选标记、已选名称标签及数量显示选择情况，收起后仍显示所选地区。当前选区按真实来源名称分组，可逐项移除。弹窗仅在遮罩上按下并松开的短点击时关闭，从内容区拖出不会误关闭。

## 配置

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `HTTP_ADDR` | `:8080` | 应用监听地址 |
| `DATA_DIR` | `./data` | 本地持久化目录，容器内为 `/app/data` |
| `ADMIN_PASSWORD` | 自动生成 | 初始管理员密码，8–1024 字节；持久账号初始化后在网页修改 |
| `MYSQL_HOST` | 空 | 现有数据库地址 |
| `MYSQL_PORT` | `3306` | 数据库端口 |
| `MYSQL_USER` | 空 | 数据库用户 |
| `MYSQL_PASSWORD` | 空 | 数据库密码 |
| `MYSQL_DATABASE` | 空 | 数据库名 |
| `MYSQL_TLS` | `false` | `true` 启用证书验证的 TLS |
| `NODEPOOL_ENV_FILE` | `.env` | 本地配置文件路径 |
| `UPDATE_GITHUB_TOKEN` | 空 | 读取私有仓库 Release 的令牌，需有目标仓库只读权限 |
| `NODEPOOL_DATA_KEY` | 空 | 数据加密密钥，32 字节 Base64 或 64 位十六进制；可用 `openssl rand -base64 32` 生成 |
| `NODEPOOL_TRUSTED_PROXIES` | 空 | 可信反向代理 IP／CIDR，逗号分隔；仅这些地址的 `X-Forwarded-For` 用于拉取风控统计 |
| `NODEPOOL_INDEX_TTL` | `5m` | 节点列表内存索引的最长刷新间隔，30s–1h；越短越实时，重建时会把全部可展示节点读一遍 |
| `NODEPOOL_SUB_CACHE_TTL` | `5m` | 订阅渲染缓存时间，30s–30m；来源内容或用户结构变化会立即失效，按客户端拉取频率调整 |

凭据不返回前端；来源 URL 与节点原配置不会由列表接口回显。来源内容和凭据存储在你配置的 MySQL 中，数据库备份与访问权限由部署者管理。

设置 `NODEPOOL_DATA_KEY` 后，来源订阅地址、原始内容、节点完整配置和服务器地址以 AES-256-GCM 加密存储（`enc1:` 前缀），启动时自动加密已有明文。密钥只放在环境变量或 `.env` 中，请单独备份：丢失或更换密钥后已加密数据无法读取；密钥不匹配时业务接口返回 503 并提示配置正确密钥，不会覆盖已有数据。加密后管理员按地址搜索节点不可用。

### 安全边界

- 订阅地址与提供方用量地址只允许公网目标：本机、内网、链路本地、运营商级 NAT 与保留网段在建源和拨号时都会被拒绝，重定向目标同样受检；主机名按解析出的地址校验后直接拨号，因此不受 DNS rebinding 影响。来源 URL 由普通用户填写，不能当作内网探测入口。
- 登录失败按出口 IP（30 次／10 分钟）与「出口 IP + 账号」（8 次／15 分钟）分别计数，超限返回 429 与 `Retry-After`，登录成功清零该组合。没有全站计数器，单个出口刷失败不会锁住其他用户。
- 出口 IP 只在直连地址属于 `NODEPOOL_TRUSTED_PROXIES` 时取自 `X-Forwarded-For`；没有配置可信代理时使用 TCP 来源地址，客户端无法伪造。
- `NODEPOOL_ALLOW_PRIVATE_TARGETS=1` 只给浏览器 e2e 和集成测试用（它们把回环地址上的模拟服务器当订阅源），生产环境不要设置。

## 积分、风控与反馈

- 经验决定等级与默认额度，实际额度 = max（等级默认，管理员单独设置）+ 积分临时扩容。签到 +5 XP／+2 积分，连续每 7 天额外 +20 XP／+8 积分；客户端有效探测续期每天 +1 XP。
- 共享奖励每日结算：来源每位其他使用者 +1 XP（单来源最多 10 人，每日最多 30 XP），按近 24 小时健康率全额／减半／不计，平台独有节点占多数时加成；另有 30／90／180 天稳定共享里程碑和一次性成就。积分为经验的 50%。
- 积分用于补签、请假延期（顺延租期）、临时扩容、兑换称号和打赏提供方，不能购买经验、等级或席位优先权。所有变动写入积分明细。
- 防提取风控：非提供方看不到节点服务器地址；每日新增节点默认不超过节点额度，30 天内累计领取的不同节点不超过额度 3 倍；单个订阅链接每小时拉取次数受限，多 IP 拉取会被标记。管理员可在用户管理查看、冻结或重置。
- 用户反馈：正在使用节点或来源的用户可反馈“无法使用／速度慢／可用”等，默认展示近 30 天内容、反馈时间、使用天数和反馈时的平台检测结果；提供方可标记已处理；确认后反馈人获得少量经验和积分，多人反馈的节点在订阅中排到末尾。以上数值均可在运行设置中调整。
- 角色：管理员拥有全部权限；用户管理员只能管理普通用户，没有系统设置权限。用户额度默认跟随等级，需要时在编辑用户中打开“单独设置额度”。
- 维护模式：开启后普通用户仍可登录、查看、签到和拉取订阅，但不能修改，页面顶部显示维护公告。
- 登录后可选择“保持登录状态”，30 天内免登录并自动续期；会话存于数据库，重启服务不掉线。
- 运行统计提供近 24 小时与近 30 天的流量柱状图；共享来源页为提供方展示使用人数、健康率和流量趋势。

## 更新、回退与发布

左上角版本文字可查看实际版本；管理员可打开发布说明和历史版本。Linux 正式版本可下载对应架构发行包，验证 `checksums.txt`，保留本地 `.backup` 后原子替换运行程序。点击“立即重启”后进程退出，Docker 的 `restart: unless-stopped` 负责拉起。

Windows 本地版本可以查看发布信息，但不执行在线替换或重启。`dev` 构建不允许在线安装；使用正式 `vX.Y.Z` 构建才开放。

回退可以恢复本地上一次程序备份，或下载安装可用的历史版本。回退不回滚 MySQL。容器内替换的程序不会改变镜像：重新创建容器时会回到所选镜像版本，因此重建时请选择对应版本的镜像。

推送稳定标签 `vX.Y.Z` 触发工作流，生成 Linux AMD64/ARM64 发行包、校验文件，以及 GHCR 多架构镜像和 GitHub Release。普通提交和 PR 只运行 CI，不发布版本。首次真实发布与真实私有资产下载仍需发版后验证。

```bash
npm run typecheck --prefix frontend
node scripts/build.mjs
cd backend
go test ./...
go vet ./...
```

真实数据库测试仅允许使用名称以 `nodepool_test` 开头的隔离测试库。设置 `MYSQL_TEST_DSN` 后运行；容量用例额外设置 `NODEPOOL_CAPACITY_TEST=1`。这些用例会清空测试库中的 `np_` 数据，禁止指向业务库。

浏览器测试位于 `e2e/`，运行前构建应用、安装测试依赖及 Chromium，并设置连接隔离库 `nodepool_browser_test` 的 MySQL 环境变量。运行 `node e2e/smoke.mjs`，覆盖账号登录、角色权限、建号、用户来源、关注、组合裁切／快照、匿名下载、令牌撤销，以及三种导入、去重、排除、搜索、真实代理延迟和移动布局。`npm run test:browser --prefix frontend` 为使用测试接口夹具的控制台回归，不能代替真实后端验收。

- `/healthz`：无需登录的存活检查。
- `/readyz`：数据库和表结构就绪检查。
- `/api/v1/system`：普通用户获取版本，管理员另获取内核、数据库、任务状态和采样时间。
- `/api/v1/statistics`：仅管理员，返回运行统计。
