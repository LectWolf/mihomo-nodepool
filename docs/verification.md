## 容量样本

本机 Windows、隔离 MariaDB 11.4.5、500 个来源，每个 20 个不同节点，共 10000 个唯一节点：

- 写入、来源关联和排期合计约 5.72 秒。
- 第二页 50 个节点、统计及来源关系查询约 60.55 毫秒。

测试生成受控配置，不包含订阅公网下载、所有节点握手和国家服务耗时。这些数值不能作为任意部署机器的性能承诺。CI 会在 MySQL 8.4 上重复该容量用例。
