# 席位租期与历史保留

状态：已按用户确认的14天方案实施，替代此前“30天不活动＋7天宽限”提案。

账号默认14天有效租期，运行设置可调整1–365天。现有账号升级后获得完整14天观察期，不根据旧账号创建日期立即过期。有效席位按来源与账号唯一；同一账号引用多个节点或多个组合只占一个席位。容量只统计启用账号未过期的有效席位，删除最后引用、踢出或过期都会释放容量；历史领取统计不再决定容量。

只有明确网页签到或有效保活探测可续期，浏览页面、登录、普通订阅拉取、后台刷新和节点检测均不续租。签到按北京时间每天奖励5经验、2积分，每连续7天额外20经验、8积分；同日可以再次续期但不会重复奖励。

个人订阅包含VLESS/WS保活节点及独立隐藏的自动检测组。服务端仅响应固定 `http://www.gstatic.com/generate_204` 的HEAD/GET，不打开出站连接。内嵌Mihomo真实URLTest覆盖握手、204响应和续期入库。只有真正探测该节点且使用支持的目标才续期；其他客户端不承诺自动探测兼容，均可回网页签到。反向代理部署须在运行设置填写真实公网HTTPS源地址，并转发 `/ws/lease/` 的WebSocket Upgrade。普通拉取附个人租期响应头，但不会改截止时间。

过期订阅保持原链接与组合选择，拉取只返回“到平台签到激活”提示节点，旧保活UUID不能复活。网页激活先校验来源是否存在、启用、满额、被禁领或等级不足；存在无法恢复来源时先返回名单，不发奖励、不改快照、不占席位。用户明确确认后归档旧组合并移除这些来源，激活其余来源并保留原订阅链接。到期后重新领取不因为历史身份绕过容量。

来源所有者或管理员可查看当前／历史订阅用户、等级、节点与组合引用数、领取／到期／最近拉取／最近续期时间。踢出会从目标全部组合移除该来源并禁止再次领取；禁领持续到明确解除，不随30天历史清理消失。不能踢出来源所有者。

历史默认保留30天，运行设置可调整1–3650天，范围包括来源事件、已结束席位和删除／覆盖／移除来源前的组合快照。快照保留显示信息，不存旧订阅令牌或连接凭据，不提供历史下载资格。历史不占有效容量；实际清理每分钟执行，查询也按保留窗口过滤。

每个来源另有 `/link/{token}` 整来源共享直链，仅owner／admin管理界面可获取和轮换。持有者即可下载，绕过个人席位与等级，不带个人保活节点；来源或提供方停用后不可用，轮换使旧链接立即失效。该链接无法识别每位匿名持有人，个人订阅的踢出限制不作用于已泄漏的来源共享直链。
